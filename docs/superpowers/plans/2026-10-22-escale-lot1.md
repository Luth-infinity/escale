# Escale, lot 1 (navigateur fonctionnel) : plan d'implémentation

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal :** un navigateur Escale qui fonctionne au quotidien : onglets verticaux, dossiers, espaces isolés, extensions Chrome, barre de commande, animations fluides, socle de sécurité.

**Architecture :**
- Electron 41. Le process principal possède tout l'état (modèle pur testé + persistance JSON / SQLite) et une `WebContentsView` par onglet vivant.
- Le shell React ne reçoit que des deltas et envoie ses intentions par un IPC gardé (expéditeur vérifié + schéma).
- Les extensions passent par `electron-chrome-extensions` + `electron-chrome-web-store`, sous réserve du spike (tâche 1).

**Tech Stack :** Electron 41, React 19, Tailwind v4, shadcn, `motion`, Vite, electron-builder, `node:test`, `node:sqlite`.

**Spec :** `docs/superpowers/specs/2026-10-22-escale-design.md`. Ce plan couvre le §6 lot 1, le §6 « Transverse », et les §3, §4, §5, §7, §8 et §9. Les lots 2 et 3, le site et le hub Luth feront l'objet de plans séparés.

**Référence de code :** `../hublink` (checkout local, faire `git fetch` avant de copier). « Porter depuis Hublink » veut dire : copier le module, retirer ce qui concerne les services et comptes, garder les commentaires utiles.

## Global Constraints

- Electron `^41.2.0`. Renderer bundlé par Vite, `dependencies` limitées aux modules chargés par le process principal (libs d'extensions).
- Main en CommonJS `.js`, renderer en `.tsx`. Noms et commentaires en français, comme Hublink.
- Commits : auteur `Luth <57181738+Luth-infinity@users.noreply.github.com>`, **aucun** trailer `Co-Authored-By`, aucune mention Posidea ni de nom réel.
- `appId: com.luthinfinity.escale`, `productName: Escale`. Licence non choisie : pas de fichier LICENSE pour l'instant.
- Toutes les `webPreferences` : `sandbox: true`, `contextIsolation: true`, `nodeIntegration: false`.
- Chaque `ipcMain.handle` passe par `ipc.handle()` (tâche 4). Aucun `ipcMain.handle` direct.
- Partitions : `persist:space-<id>`, figée à la création de l'espace.
- Animations : `transform` / `opacity` uniquement, ressorts `motion` interruptibles, 150 à 250 ms. `prefers-reduced-motion` → fondu de 100 ms.
- Aucune couleur en dur dans le shell : tokens `--shell-*` et `--accent-escale`.
- Interdits de DA : glassmorphism, dégradés, `border-left` coloré arrondi, animation décorative.
- Avant tout test Electron : `pkill -9 -f "escale/node_modules/electron"`.
- Ne jamais lancer `vite build` pendant `npm run dev`.

## Review Focus

1. **Clics rapides pendant le chargement** (onglet A, B puis C avant que A ait fini) → c'est la vue du dernier clic qui s'affiche, et la barre latérale le montre actif. Test : tâche 6.
2. **`escale.json` corrompu ou tronqué** (crash pendant l'écriture) → l'app démarre, garde le fichier en `escale.json.corrompu-<date>` et repart du dernier état valide ou d'un état neuf, sans planter. Test : tâche 3.
3. **Supprimer un dossier non vide ou le dernier espace** → les onglets du dossier remontent au parent (jamais supprimés en silence), et le dernier espace ne peut pas être supprimé. Test : tâche 2.
4. **Popup ou `target=_blank` depuis un onglet de l'espace A** → ouvert dans un nouvel onglet de l'espace A, avec la même partition. Une popup OAuth reste une fenêtre fille de la même session. Test : tâche 6.
5. **Titres très longs, page sans favicon, favicon `data:,`** → titre tronqué en ellipse sur une ligne, repli sur l'initiale du domaine, jamais de glyphe d'image cassée. Test : tâche 8.
